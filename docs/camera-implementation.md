## 功能說明

### 1. 攝影機跟隨玩家

```typescript
this.cameras.main.startFollow(this.player.sprite, true, 0.1, 0.1)
```

**參數說明：**
- `this.player.sprite` - 跟隨目標（玩家精靈）
- `true` - 啟用像素對齊（roundPixels），防止次像素渲染造成的模糊
- `0.1` - 水平方向的 lerp 插值係數
- `0.1` - 垂直方向的 lerp 插值係數

### 2. 平滑跟隨效果（Lerp）

**Lerp（線性插值）原理：**

```
新位置 = 當前位置 + (目標位置 - 當前位置) × lerp係數
```

使用 lerp 係數 `0.1` 表示：
- 每幀攝影機會移動「當前位置到目標位置距離」的 10%
- 這創造出平滑、漸進的跟隨效果
- 而不是瞬間跳躍到目標位置

**係數選擇考量：**
- `< 0.05`：攝影機跟隨太慢，玩家會感覺延遲
- `0.05 - 0.15`：適合動作遊戲的平滑跟隨（✅ 當前使用 0.1）
- `0.15 - 0.3`：較快的跟隨，適合快節奏遊戲
- `> 0.3`：跟隨太快，失去平滑感

### 3. 攝影機邊界設定

```typescript
this.cameras.main.setBounds(0, 0, MAP_WIDTH, MAP_HEIGHT)
```

**功能：**
- 設定攝影機可移動的範圍為整個地圖（5000 × 5000 像素）
- 當玩家接近地圖邊緣時，攝影機會自動停止滾動
- 防止攝影機顯示地圖外的空白區域

**邊界約束行為：**
- 玩家在地圖中央：攝影機正常跟隨，玩家位於螢幕中心
- 玩家接近左/上邊界：攝影機停止向左/上移動，玩家偏離螢幕中心
- 玩家接近右/下邊界：攝影機停止向右/下移動，玩家偏離螢幕中心

## 效能考量

1. **像素對齊（roundPixels: true）**
   - 防止次像素渲染造成的效能損耗
   - 避免精靈模糊

2. **Lerp 插值**
   - 使用簡單的線性插值，計算成本低
   - 每幀只需一次乘法和加法運算

3. **邊界檢查**
   - Phaser 內建的邊界檢查，效能優化良好
   - 不需要手動實作邊界限制邏輯
